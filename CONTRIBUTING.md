# Contributing to Testrium

Contributions are welcome when submitted under the repository's current
licensing process.

Before submitting a pull request:

1. read `LICENSE.md`, `NOTICE.md`, and `CLA.md`;
2. confirm you wrote the contribution or have authority from its owner;
3. identify all third-party code, assets, and licenses;
4. add tests for behavior changes; and
5. record CLA acceptance in the pull request.

Contributors retain authorship and receive credit in Git history and, for
substantial accepted work, `AUTHORS.md`. CLA acceptance grants licensing rights;
it does not assign copyright ownership.

Contributions cannot be merged until CLA acceptance and third-party licensing
have been reviewed.
